# GI421 Final Exam – Rendering Optimization

## Objective
Optimize the rendering performance of the provided Unity project by reducing the number of rendering batches while maintaining the visual quality of each scene.

---

## Repository

Fork the original project:

**Original Repository:**  
https://github.com/anak-ladachat/GI421-final-exam

Complete your work in your fork and push all changes to the required feature branch.

---

## Scenes to Optimize

Optimize the following scenes:

- Exam_Scene_1
- Exam_Scene_2
- Exam_Scene_3

---

## Requirements

### Primary Goal
- Reduce the rendering batches as much as possible.

### Scoring
- Score is based on the number of batches reduced.
- Fewer batches = Higher score.

### Bonus
- Maintain the visual quality of the scene.
- Preserve lighting quality whenever possible.
